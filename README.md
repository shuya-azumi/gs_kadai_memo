# 🕐 Task Timer - タスク時間管理アプリ

G's academy JavaScript課題（js_02_memo）の発展版として作成した、ブラウザだけで動くタスク時間管理アプリです。

## 概要

スプレッドシートで管理していた「今日やること・予定時間・実績時間」を、ボタンひとつで記録できるWebアプリにしました。

- **タスクを登録** → 予定時間と種別（作業/会議/雑務/休憩）を入力
- **▶開始ボタン**で計測スタート、**⏹終了ボタン**で実績時間を自動計算
- データはブラウザの `localStorage` に保存されるので、リロードしても消えません

## 機能

| 機能 | 説明 |
|---|---|
| タスク追加 | タスク名・予定時間（分）・種別を入力して保存 |
| 一覧表示 | 登録したタスクを一覧表示。状態（todo/doing/done）で色分け |
| ▶開始 / ⏹終了 | ボタン押下で開始時刻を記録し、終了で実績時間を計算 |
| 削除（×） | 1件ずつ削除 |
| 全て削除 | 全データを一括削除（確認ダイアログあり） |
| 次のタスク表示 | 未着手の先頭タスクを「👉次のタスク」として強調 |
| 本日合計 | 予定時間と実績時間の合計を自動集計 |

## 使用技術

- HTML / CSS
- JavaScript（jQuery 2.1.3）
- `localStorage`（ブラウザのデータ保存）

## データ設計

1タスクを1 localStorageエントリとして保存しています。

### key

```
"task_" + 追加時刻(ミリ秒)
例: "task_1716512345678"
```

タスク追加時の `new Date().getTime()` を使うため、必ずユニークなIDになります。

### value

カンマ区切り文字列（7項目）

```
"タスク名,予定分,種別,状態,開始時刻,実績秒,ソース"
```

| # | フィールド | 例 | 説明 |
|---|---|---|---|
| 0 | タスク名 | `資料作成` | 表示用 |
| 1 | 予定(分) | `60` | 集計に使う |
| 2 | 種別 | `作業` | 作業/会議/雑務/休憩 |
| 3 | 状態 | `todo` | todo / doing / done |
| 4 | 開始時刻 | `1716512400000` | ▶開始時のミリ秒 |
| 5 | 実績(秒) | `0` | ⏹終了で加算される |
| 6 | ソース | `manual` | 手動入力。Phase 2で `gcal`/`slack` 等を予定 |

復元するときは `value.split(",")` で配列に戻します。

## 工夫したポイント

1. **講義で学んだ範囲で完結**
   `localStorage.setItem / getItem / key / length / removeItem / clear`、`for`ループ、jQuery、テンプレートリテラルのみを使用。
2. **カンマ区切りで複数項目を保存**
   講義サンプルは「key:タイトル, value:本文」の2項目だったが、value を `,` 区切りにすることで7項目を保存できるよう拡張。
3. **状態(status)で表示を切り替え**
   `todo` → ▶開始、`doing` → ⏹終了、`done` → ✅完了 と状態によってボタンが変わる。
4. **再描画関数 `redraw()` を用意**
   追加・削除・状態変更のたびに `redraw()` を呼ぶ。一覧表示と集計のロジックを1か所にまとめた。
5. **動的ボタンのクリック処理**
   一覧の中のボタンは後から作られるので `$(document).on("click", ".btn-xxx", ...)` で受ける。
6. **将来の拡張に備えたフィールド**
   現状では `manual` 固定の「ソース」欄を持たせ、Phase 2でGoogleカレンダーやSlackから取得した時間を追加できる構造にした。
